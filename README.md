# AI Code Review Assistant

An intelligent code review assistant powered by Groq AI that provides instant optimization, readability, and security suggestions for your code.

## ✨ Features

- **🤖 AI-Powered Analysis**: Leverages Groq's powerful LLM models for comprehensive code review
- **📊 Quality Scoring**: Get an overall code quality score (1-10)
- **⚡ Optimization Suggestions**: Receive specific recommendations to improve performance
- **📖 Readability Improvements**: Enhance code clarity and maintainability
- **🔒 Security Analysis**: Identify potential security vulnerabilities
- **✅ Best Practices**: Learn industry-standard coding practices
- **🎯 Multi-Language Support**: Works with Python, JavaScript, Java, C++, Go, and more
- **🚀 Fast & Free**: Uses Groq API for lightning-fast responses


## 🚀 Usage

1. **Enter API Key**: Paste your Groq API key in the sidebar
2. **Select Language**: Choose your programming language from the dropdown
3. **Paste Code**: Copy and paste your code into the text area
4. **Review**: Click "Review Code" and get instant feedback!

## 📋 Review Categories

The assistant provides feedback in these areas:

- **Quality Issues**: Code smells, bugs, and anti-patterns
- **Optimizations**: Performance improvements and efficiency tips
- **Readability**: Code clarity and documentation suggestions
- **Best Practices**: Industry standards and conventions
- **Security Concerns**: Vulnerability identification
- **Strengths**: Positive aspects of your code

## 🔧 Configuration

Adjust these settings in the sidebar:

- **Model Selection**: Choose between different LLM models
- **Temperature**: Control creativity (0.0 = focused, 1.0 = creative)
- **Language**: Select from 12+ programming languages
